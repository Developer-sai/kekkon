# Kekkon User Guide

## Overview

Kekkon is a modern wedding invitation application that allows you to create beautiful, digital wedding invitations with multiple sub-events, image galleries, and social media integration. This guide covers how to use the admin dashboard to manage your wedding events.

## Getting Started

### Accessing the Admin Dashboard

1. Navigate to your Kekkon application URL
2. Click on the "Admin" link in the header or go to `/admin`
3. Enter your admin credentials:
   - **Username**: admin (or your configured username)
   - **Password**: Your secure password
4. Click "Login" to access the dashboard

### Dashboard Overview

The admin dashboard provides:
- **Event Creation**: Create new wedding events
- **Event Management**: View and manage existing events
- **Live Preview**: See how your invitation will look to guests
- **QR Code Generation**: Automatic QR codes for easy sharing

## Creating Your First Event

### Step 1: Basic Event Information

1. Click "Create New Event" button
2. Fill in the main event details:
   - **Event Title**: Your wedding title (e.g., "Sarah & John's Wedding")
   - **Description**: Brief description of your special day
   - **Date**: Select your wedding date
   - **Time**: Enter the start time
   - **Venue**: Location name
   - **Maps Link**: Google Maps URL for easy navigation
   - **Instructions**: Special instructions for guests

### Step 2: Social Media Links

Add your social media profiles for guests to connect:

1. Click "Add Social Link" 
2. Enter platform name (e.g., "Instagram", "Facebook")
3. Enter the full URL to your profile
4. Add multiple links as needed
5. Remove unwanted links using the "×" button

### Step 3: Sub-Events

Create multiple events within your wedding day:

1. Click "Add Sub-Event" (up to 5 sub-events allowed)
2. For each sub-event, enter:
   - **Title**: Event name (e.g., "Ceremony", "Reception", "After Party")
   - **Description**: Details about this specific event
   - **Date**: Date for this sub-event (can be different from main event)
   - **Time**: Start time for this sub-event
   - **Venue**: Location for this sub-event
   - **Maps Link**: Specific location URL
   - **Instructions**: Special notes for this event

#### Sub-Event Examples:
- **Ceremony**: Church service at 4:00 PM
- **Cocktail Hour**: Garden reception at 5:30 PM  
- **Dinner**: Ballroom dining at 7:00 PM
- **Dancing**: Party until midnight
- **After Party**: Late night celebration

### Step 4: Image Upload

#### Cover Image
1. Click "Choose Cover Image"
2. Select a high-quality image (recommended: 1200x800px)
3. This will be the main image guests see first

#### Gallery Images
1. Click "Choose Gallery Images"
2. Select multiple images for your photo gallery
3. These will be displayed in a beautiful grid layout
4. Recommended: 6-12 high-quality photos

### Step 5: Preview Your Event

1. Use the live preview panel on the right side
2. Check how your invitation looks on different screen sizes
3. Verify all information is correct
4. Make adjustments as needed

### Step 6: Create the Event

1. Review all information one final time
2. Click "Create Event"
3. Wait for the success message
4. Your event is now live and accessible to guests

## Best Practices

### Event Information
- **Be Specific**: Include exact addresses and times
- **Add Context**: Explain dress codes, parking, etc.
- **Update Regularly**: Keep information current
- **Test Links**: Verify all maps and social links work

### Images
- **High Quality**: Use clear, well-lit photos
- **Variety**: Mix engagement, venue, and couple photos
- **Appropriate Size**: Optimize for web (under 2MB each)
- **Consistent Style**: Maintain a cohesive visual theme

### Sub-Events
- **Logical Order**: Arrange events chronologically
- **Clear Titles**: Use descriptive names
- **Detailed Descriptions**: Help guests understand each event
- **Realistic Timing**: Allow buffer time between events

### Social Media
- **Active Profiles**: Link to profiles you actively use
- **Consistent Branding**: Use the same handle across platforms
- **Privacy Settings**: Adjust privacy as needed for wedding content

## Troubleshooting

### Common Issues

#### Can't Login to Admin
- Verify username and password
- Check for typos
- Contact your developer if credentials are forgotten

#### Images Not Uploading
- Check file size (must be under 10MB)
- Ensure file format is JPG, PNG, or WebP
- Try a different browser
- Check internet connection

#### Event Not Displaying Correctly
- Refresh the page
- Clear browser cache
- Check all required fields are filled
- Verify image URLs are working

#### Maps Links Not Working
- Use full Google Maps URLs
- Test links before saving
- Ensure URLs start with "https://"

### Getting Help

If you encounter issues:
1. Try refreshing the page
2. Clear your browser cache
3. Try a different browser
4. Contact your developer or support team

## Tips for Success

### Planning Your Digital Invitation
1. **Start Early**: Create your invitation 2-3 months before the wedding
2. **Gather Content**: Collect all photos and information first
3. **Review Carefully**: Double-check all details before publishing
4. **Test Thoroughly**: View on different devices and browsers
5. **Share Strategically**: Send to close family first for feedback

### Maximizing Guest Engagement
- **Update Regularly**: Add new photos and information
- **Encourage Sharing**: Ask guests to share on social media
- **Provide Value**: Include helpful information like weather, accommodations
- **Make it Personal**: Add personal touches and stories

### Timeline Management
- **Buffer Time**: Add 15-30 minutes between events
- **Consider Travel**: Account for transportation time
- **Weather Backup**: Include backup plans for outdoor events
- **Guest Needs**: Consider elderly guests and families with children
